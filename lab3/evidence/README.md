# Evidence Capture Checklist

Create `evidence/screenshots/` locally and add the screenshots below. Do not fabricate screenshots; capture them from the authorized lab environment.

1. `01-ansible-check.png`: successful Ansible syntax/check output.
2. `02-terraform-plan.png`: Terraform plan with `replicas=2`.
3. `03-kibana-logs.png`: Kibana Discover with `lab3-logs-*` records and parsed `app_event.message`.
4. `04-security-scan.png`: pipeline or Trivy/pip-audit scan output.
5. `05-grafana-dashboard.png`: Demo Application Overview dashboard after traffic generation.
6. `06-testing.png`: Locust statistics and Selenium pytest success output.

Record dates, environment details, commands, and observations in `report/Lab3_Report.docx` before submission.
